# تطبيق جامعة المعقل الأهلية · قسم هندسة الأمن السيبراني

تطبيق ويب تقدّمي (PWA) واحد يعمل على **أندرويد** و**آيفون/آيباد** و**الكمبيوتر (Windows / macOS / Linux)**، ويُثبَّت بأيقونة على الشاشة الرئيسية ويفتح بملء الشاشة كتطبيق حقيقي، ويعمل بدون إنترنت بعد أول فتح.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق (صفحتك الأصلية + زر التثبيت + شريط تنقل سفلي للموبايل) |
| `app.css` | تنسيقات Tailwind مجمّعة محلياً (أسرع، وتعمل أوفلاين) |
| `manifest.webmanifest` | تعريف التطبيق: الاسم، الأيقونات، الألوان، الاختصارات |
| `sw.js` | Service Worker للعمل بدون إنترنت وإشعار التحديثات |
| `offline.html` | صفحة تظهر عند انقطاع الاتصال |
| `icons/` | أيقونات التطبيق بكل المقاسات (أندرويد، آيفون، ويندوز) |

## 1) النشر (خطوة واحدة)

التطبيق يحتاج رابط **HTTPS** ليُثبَّت. أسهل طريقة: GitHub Pages الذي تستخدمه أصلاً.

1. افتح المستودع `drdshsw2022-byte/almaaqal` على GitHub.
2. ارفع **كل محتويات هذا المجلد** (مع مجلد `icons`) إلى جذر المستودع، واستبدل `index.html` القديم.
3. من **Settings → Pages** تأكد أن المصدر هو فرع `main` والمجلد `/ (root)`.
4. بعد دقيقة يصبح التطبيق متاحاً على: `https://drdshsw2022-byte.github.io/almaaqal/`

> بديل: يمكن رفع المجلد كما هو على Netlify (سحب وإفلات) أو على سيرفر `it-basra.com`.

## 2) التثبيت على الأجهزة

**أندرويد (Chrome):** افتح الرابط ← اضغط زر «تثبيت التطبيق» أعلى الصفحة ← «تثبيت».

**آيفون / آيباد (Safari):** افتح الرابط ← اضغط «تثبيت التطبيق» لتظهر خطوات مصوّرة ← المشاركة ⬆ ← «إضافة إلى الشاشة الرئيسية».

**الكمبيوتر (Chrome / Edge):** افتح الرابط ← زر «تثبيت التطبيق» أو أيقونة التثبيت في شريط العنوان. يظهر التطبيق في قائمة ابدأ / Launchpad.

## 3) (اختياري) ملف APK ومتاجر التطبيقات

لتحويل نفس التطبيق إلى ملف APK أو حزمة متجر Microsoft بدون كتابة كود:

1. بعد النشر، ادخل إلى **https://www.pwabuilder.com**
2. ألصق رابط التطبيق واضغط Start.
3. اختر **Android** لتنزيل APK/AAB (للتوزيع المباشر أو Google Play)، أو **Windows** لمتجر Microsoft، أو **iOS** لمشروع Xcode (يحتاج جهاز Mac وحساب مطوّر Apple).

بعدها يمكنك رفع الـ APK الجديد مكان `almaqal-12.apk` على السيرفر.

## 4) إصدار تحديث

عدّل الملفات، ثم غيّر رقم الإصدار في أول `sw.js`:

```js
const VERSION = 'amu-v1.0.1';
```

عند فتح التطبيق يظهر للمستخدمين شريط «يتوفر تحديث جديد» بزر تحديث.

## 5) لو أضفت كلاسات Tailwind جديدة

`app.css` مجمّع مسبقاً من الكلاسات الموجودة حالياً. إذا أضفت كلاسات جديدة لم تكن مستخدمة، أعد التجميع:

```bash
npm i -D tailwindcss@3
npx tailwindcss -i input.css -o app.css --minify
```

(حيث `input.css` يحتوي `@tailwind base; @tailwind components; @tailwind utilities;` وملف `tailwind.config.js` يشير إلى `index.html`).
